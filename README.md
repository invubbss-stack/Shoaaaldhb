# QR Pro — ماسح ومنشئ رموز QR

تطبيق ويب احترافي بنمط SPA و PWA يدعم العربية RTL والإنجليزية، يعمل دون Backend، ويستخدم LocalStorage لحفظ السجل والتفضيلات.

## بنية الملفات

```text
/qr-pro
├── index.html
├── style.css
├── app.js
├── manifest.json
├── service-worker.js
└── assets
    ├── logo.svg
    └── icons/
```

## المزايا

- ماسح QR حقيقي عبر كاميرا الجهاز باستخدام `getUserMedia` ومكتبة `html5-qrcode`.
- قراءة QR من صورة محلية.
- منشئ QR حقيقي عبر `qr-code-styling` مع ألوان، أنماط، شعار، حجم، هامش، وتصحيح أخطاء.
- تحميل PNG و SVG، نسخ ومشاركة عبر Web Share API مع بديل نسخ النص.
- سجل محلي قابل للبحث والفلترة والترتيب والحذف.
- إعدادات الثيم واللغة والاهتزاز والصوت والحفظ التلقائي.
- تصميم Mobile First متجاوب مع Bottom Navigation للهاتف و Sidebar للحاسوب.
- PWA قابل للتثبيت مع Service Worker و Manifest.

## التشغيل محليًا

1. ضع الملفات في مجلد واحد.
2. شغّل خادم ملفات ثابت لأن الكاميرا و Service Worker يحتاجان سياقًا آمنًا أو localhost:

```bash
python3 -m http.server 8000
```

3. افتح المتصفح على:

```text
http://localhost:8000
```

4. لاختبار الهاتف، افتح عنوان الجهاز على نفس الشبكة أو استخدم نفق HTTPS، ثم اسمح بالكاميرا.
5. اختبر صفحة الماسح، ثم المنشئ، ثم السجل.

> يحتاج التطبيق اتصال إنترنت أول مرة لتحميل مكتبات CDN والخط، ثم يخزن الملفات الأساسية للعمل دون اتصال.
